Welcome to IoT Security Awareness

The Internet of Things connects everyday devices to the internet, allowing them to communicate and share information. Smart TVs, security cameras, smart watches and other connected devices are now common in modern homes.

However, using these devices without proper security can expose personal information and create privacy risks. This website helps users understand these risks and learn simple ways to stay protected.

🔐 Data Protection

Protect personal information from unauthorized access.

Prevent unknown users from controlling your connected devices.

🔒 Privacy Protection

Keep private conversations, activities and home information secure.

About This Project

This project focuses on studying IoT device usage and security concerns in urban homes through a field survey. It also aims to improve public awareness about safe usage of connected devices.

Users can explore security information, participate in a survey and learn simple methods to improve their home device security.
